# Retrieve the fitted model, if appropriate, from a loadModel load model

Retrieve the fitted model, if appropriate, from a loadModel load model

## Usage

``` r
# S3 method for class 'loadModel'
getFittedModel(load.model)
```

## Arguments

- load.model:

  The load model for which to return the inner fitted model.
