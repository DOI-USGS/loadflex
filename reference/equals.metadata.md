# Basic equality test for two metadata objects.

Compares the contents of each slot using the == operator.

## Usage

``` r
# S4 method for class 'metadata,metadata'
e1 == e2
```

## Arguments

- e1:

  metadata object to be compared.

- e2:

  metadata object to be compared.

## Value

logical value indicating whether the two metadata objects have identical
contents.
