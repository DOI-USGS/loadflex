# Retrieve the data used to fit the model

Retrieve the data used to fit the model

## Usage

``` r
# S3 method for class 'loadModel'
getFittingData(load.model)
```

## Arguments

- load.model:

  A load model, implementing the loadModelInterface, for which to return
  the fitting data
