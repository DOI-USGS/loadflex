# Retrieve a fitting function from a loadModel load model

Retrieve a fitting function from a loadModel load model

## Usage

``` r
# S3 method for class 'loadModel'
getFittingFunction(load.model)
```

## Arguments

- load.model:

  The model for which to return a new fitting function.
