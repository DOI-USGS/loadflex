# Retrieve metadata from a loadModel load model

Retrieve metadata from a loadModel load model

## Usage

``` r
# S3 method for class 'loadModel'
getMetadata(load.model)
```

## Arguments

- load.model:

  A load model, implementing the loadModelInterface, for which to return
  the metadata
