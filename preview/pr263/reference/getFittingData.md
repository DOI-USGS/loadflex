# Extract the data originally used to fit a load model.

A function in the loadModelInterface.

## Usage

``` r
getFittingData(load.model)
```

## Arguments

- load.model:

  A load model, implementing the loadModelInterface, for which to return
  the fitting data

## Value

data.frame containing the original fitting data
