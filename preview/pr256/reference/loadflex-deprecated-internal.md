# Deprecated internal functions in the loadflex package

These functions were formerly private functions in loadflex but are now
deprecated and may be removed in the future. See the Details section for
suggestion on where to look instead.

## Usage

``` r
generateUnitsData()
```

## Details

`generateUnitsData` (defunct as of v1.2.0) has been replaced by the
script at data-raw/createUnitsData.R
