# Get summary statistics for a single input data.frame

Get summary statistics for a single input data.frame

## Usage

``` r
summarizeTimeseries(metadata, data)
```

## Arguments

- metadata:

  object of class metadata, describing the site and data

- data:

  data.frame of input data, either for model fitting (concentration and
  discharge) or prediction (discharge only)

## Value

data frame of statistics about the input data
