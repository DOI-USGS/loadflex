# Extracts and imports metadata from an rloadest loadReg model into an object of class "metadata"

Extracts and imports metadata from an rloadest loadReg model into an
object of class "metadata"

## Usage

``` r
# S3 method for class 'loadReg'
getMetadata(load.model)
```

## Arguments

- load.model:

  a loadReg object

## Value

Object of class "metadata" with slots modified according to the metadata
contained in load.model
